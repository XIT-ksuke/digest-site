GitHub Digest

GitHubで最近伸びている新しいリポジトリを定期的にまとめ、解説メールと解説動画を自分宛に届ける、個人用の自動化ツールです。

何をするものか

数日おきに GitHub の公開APIを検索し、「作成されて日が浅く、スターが一定数以上集まっているリポジトリ」を数件選びます。選んだリポジトリのREADMEをもとに日本語の解説文と短い解説動画（1〜2分）を作り、運用者本人のメールアドレス宛に1通のメールとして届けます。

GitHub Actions 上で動く個人用のツールで、一般の利用者に向けて公開しているサービスではありません。アカウント登録もログイン機能もありません。

Google Drive の使い方

生成した解説動画の保存先として、運用者本人の Google Drive を使います。利用するのはこのアプリが作成した専用フォルダと、その中のファイルだけです。

  • 権限は drive.file のみ（このアプリが作成したファイルとフォルダに限定されます）
  • 本人のDrive内にある他のファイルやフォルダは参照しません
  • 保存容量の上限を超えそうなときは、このアプリが作成した古い動画だけを削除します
  • アップロードしたファイルの共有設定は変更しません（本人だけが閲覧できる状態のままです）

扱う情報

扱うのは GitHub の公開情報（リポジトリ名、説明、スター数、作成日、README など）と、そこから生成した解説文・動画だけです。閲覧者の情報を集める仕組み、アクセス解析、広告はありません。

詳しくはプライバシーポリシーをご覧ください。
