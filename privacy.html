プライバシーポリシー

GitHub Digest ／ 最終更新日：2026年11月1日

1. このアプリについて

GitHub Digest（以下「本アプリ」）は、個人が自分のためだけに運用している自動化ツールです。一般の利用者に向けて提供しているサービスではなく、利用者登録・ログイン・問い合わせフォームなどの仕組みはありません。

2. 収集する情報

本アプリは、閲覧者や第三者の個人情報を収集しません。

  • アカウント登録はありません
  • アクセス解析ツール、広告、トラッキング用Cookieは使用していません
  • 扱うのは GitHub の公開APIから取得できる公開情報（リポジトリ名、説明、スター数、作成日、READMEなど）と、そこから生成した解説文・動画だけです

3. Google ユーザーデータの取り扱い

本アプリは、生成した動画の保存先として運用者本人の Google Drive を利用します。要求する権限は drive.file のみで、これは本アプリが作成したファイルおよびフォルダに限定された権限です。

  • 本アプリが作成した専用フォルダ以外の、Drive内の既存のファイルやフォルダにはアクセスしません
  • 読み取るのは、本アプリが保存した動画のファイル名・サイズ・更新日時・IDだけです（容量管理とリンク生成のために使います）
  • 保存容量の上限を超えそうな場合、本アプリが作成した古い動画のみを削除します
  • アップロードしたファイルの共有設定は変更しません（本人だけが閲覧できる状態のままです）
  • 取得したデータを学習用途に利用したり、広告に利用したりすることはありません

本アプリによる Google ユーザーデータの利用は、Google API Services User Data Policy（限定使用（Limited Use）の要件を含む）に準拠します。

4. 第三者への提供

本アプリが扱うデータを第三者に提供・販売・共有することはありません。生成した解説文・動画・メールは、運用者本人だけが受け取ります。

5. 認証情報の保管

Google Drive やメール送信に使う認証情報は、GitHub Actions の暗号化されたシークレットとして保管し、処理中のログには出力しません。認証情報を外部に送信することはありません。

6. データの削除とアクセス権の取り消し

Google Drive に保存されたファイルは、運用者本人がいつでも Drive 上で削除できます。本アプリへのアクセス権は、Google アカウントのセキュリティ設定（サードパーティ製アプリとサービスとの連携）からいつでも取り消せます。取り消した時点で、本アプリは Drive 上のいかなるデータにもアクセスできなくなります。

7. ポリシーの変更

内容を変更した場合は、このページを更新し、最終更新日を書き換えます。
